# Remote PC download site

A responsive, static product page for the Remote PC desktop and Android apps. The site uses a real screenshot of the desktop application for the product preview, plus the shared Remote PC brand mark. The feature-card illustrations are small conceptual previews; AirPulse is labeled as in development.

Preview locally from the repository root:

```sh
python3 -m http.server 8000
```

Then open `http://localhost:8000/website/`. Download buttons point to the matching assets in the GitHub Releases `latest` endpoint.
